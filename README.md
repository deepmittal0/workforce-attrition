# Workforce Attrition & Headcount Analytics

Portfolio project using synthetic employee data. It profiles headcount, data quality, and attrition by department.

## Run
```bash
python -m pip install -r requirements.txt
python src/analyze.py
```
Outputs: `reports/summary.json` and `reports/department_attrition.csv`.

All records are synthetic; figures are illustrative, not claims about a real employer.
